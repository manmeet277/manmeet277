### `01`

# LINGOCORRECT AI

**Natural Language Processing · Transformers · Grammar Correction**

</div>

An AI-powered grammar correction system built to identify and correct grammatical errors in natural-language text.

The project uses a **Transformer-based sequence-to-sequence model** and exposes the model through a backend API, with a web interface providing an accessible way for users to submit and receive corrected text.

**Built with**

`Python` `FastAPI` `Hugging Face` `Transformers` `T5` `NLTK` `JavaScript`

**Pipeline**

```text
User Input
    ↓
Frontend
    ↓
FastAPI
    ↓
Tokenizer
    ↓
T5 Grammar Model
    ↓
Generated Correction
    ↓
Frontend Output
```

**Deployment**

`Hugging Face` · `Vercel`

→ **[View project](https://github.com/manmeet277)**

### `02`

# WEATHER PREDICTION

**Machine Learning · Predictive Analytics · Data Visualization**

</div>

A machine-learning based weather prediction application developed using historical weather data.

The project explores weather-related features, performs data preprocessing and outlier handling, trains classification models, and presents predictions through an interactive application.

A **Random Forest Classifier** was selected for the final model, with the application integrating prediction and visualisation into a user-friendly interface.

**Features**

`Temperature` · `Humidity` · `Precipitation` · `Wind Speed` · `Pressure` · `Solar Radiation` · `Month`

**Built with**

`Python` `Pandas` `NumPy` `Scikit-learn` `Random Forest` `Streamlit` `Plotly`

**Workflow**

```text
Historical Weather Data
          ↓
    Data Cleaning
          ↓
   Outlier Detection
          ↓
   Feature Selection
          ↓
   Machine Learning
          ↓
 Random Forest Model
          ↓
       Prediction
          ↓
   Interactive Dashboard
```

→ **[View project](https://github.com/manmeet277)**
